01 Features

Everything your
server needs.

The planned feature set brings core server management and community tools into one configurable bot.

MD

Moderation

Ban, kick, mute, warnings, and automated tools for managing server safety.

MU

Music

Queue-based playback with straightforward controls for members and moderators.

VC

Tempo voice

Temporary voice channels that are created when needed and removed when empty.

TK

Ticket system

Structured support requests with categories, permissions, and transcripts.

XP

Leveling

Experience, leaderboards, and role rewards for community participation.
