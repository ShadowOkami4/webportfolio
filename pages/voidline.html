01 System

A shell built
in layers.

The showcase presents the intended visual direction for a cohesive experience around Hyprland, with different technologies handling the parts they suit best.

UI

Cohesive experience

Panels, launchers, notifications, and controls are planned to feel like one consistent layer around Hyprland.

M3

Material theming

Color, shape, elevation, and layout are coordinated through a Material-inspired design language.

FX

Purposeful motion

Transitions are designed to communicate state changes while keeping the interface responsive.

HY

Hyprland centered

Voidline is designed as a shell and experience around Hyprland, with Hyprland remaining the underlying window manager.

MIX

Multi-language foundation

Quickshell, Python, Lua, and Rust are planned to work together across the interface, automation, configuration, and supporting tools.

OS

Public showcase

The showcase repository makes the concept, experiments, and current state available to inspect.

02 Installation

From blank
to Voidline.

Because this is an AI-generated experimental showcase, the commands and configuration may be incomplete or change without notice. Review the repository and back up your config first.

01 / 05

Install Hyprland

sudo pacman -S hyprland kitty
02 / 05

Install Quickshell

yay -S quickshell-git
03 / 05

Clone Voidline

git clone https://github.com/ShadowOkami4/Voidline_Showcase ~/.config/quickshell
04 / 05

Copy the config

cp -r ~/.config/quickshell/hypr ~/.config/
05 / 05

Start Hyprland

start-hyprland
